# Public Claims Guide

## Safe concise description
Cafe Sys is a Flutter Windows café operations project with separate POS and KDS applications backed by a local Dart/Shelf service and Drift/SQLite persistence. Its implemented domain covers menu customization, table/preparation workflows, payment records, recipe-driven inventory costing, and customer/delivery foundations. The project remains in development with UI integration, security, concurrency, hardware, and release-hardening work remaining.

## Safe recruiter bullets
- Built separate Flutter Windows POS and KDS clients around a local Dart/Shelf service and Drift/SQLite persistence.
- Modeled menu customization, table/check workflows, held/fired preparation, and recipe-driven inventory costing.
- Added domain, widget, API, migration, and recovery testing across 124 tracked test files.

## Claims to avoid
- Production-ready
- In production
- 653 passing tests
- Fully secure / fully enforced RBAC
- Online card payments
- Offline client selling and later sync
- Verified revenue / customers / waste reduction / time savings
